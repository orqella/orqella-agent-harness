Agents

Agent registry

Define the agents available in the workspace. Agents use their own login and configuration; credentials are never stored here. The default for new conversations is set in Settings → Agents.

Adapter fallback

npx

Enable Allow adapter fallback in Settings → Agents → Workspace to run a harness's documented npx adapter when its binary is not on PATH. Requires Node and network access on this machine.

Add a custom harness

exec

A custom harness runs a command once per prompt. Use {prompt} in an argument, or the prompt is appended. JSON output is scanned for session_id, thread_id, or conversation_id.
